    Troubleshooting¶

    User guide › Troubleshooting

    FSD Trim Speed XP is not in the Plugins menu¶

    Check the folder layout: the path must be Resources/plugins/TrimSpeedXP/64/ with the .xpl files inside 64. A common mistake is an extra folder level, such as plugins/TrimSpeedXP/TrimSpeedXP/64. On a Mac, also see the note under Installation.

    The trim wheel moves the trim the wrong way¶

    The two wheel directions are assigned the other way round. Assign them again: Trim up gets the nose-up direction.

    One press moves the trim twice, or by the wrong amount¶

    The same key or button probably also has a trim command in X-Plane. For joystick buttons, tick Block X-Plane's own assignment on these buttons. For keyboard keys, remove the key from X-Plane's trim commands in Settings › Keyboard.

    Nothing happens when I press my hotkey¶

    Check that Enable Trim Speed is ticked and that the aircraft has its own settings (see This aircraft). Use the Test buttons to check that the trim moves.

    Something else seems wrong¶

    Open X-Plane 12/Log.txt and search for lines that start with [TrimSpeedXP]. Please include them when you report a problem.

    Where your settings are stored¶

    X-Plane 12/Output/preferences/TrimSpeedXP/settings.json

    This file holds your hotkeys and the settings for every aircraft. It is not touched when you update or reinstall the plugin. Back it up if you reinstall X-Plane.
